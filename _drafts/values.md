# Draft values

Drafts for the Values section of `values.html`, taken off the page until they're rewritten in my own words. GitHub Pages doesn't publish folders that start with `_`, so nothing here is on the site.

To use one, copy it into the commented-out `<li class="value">` template in `values.html`.

1. **Do hard things on purpose.** Ironman-distance triathlons, Half Dome, Seattle to DC by bike. The long, uncomfortable stretch is where I learn the most.
2. **Understand, don't just build.** I want to know why something works, whether it's a robot's policy or a neuron's firing, not only that it does.
3. **Build for everyone.** The best tools let anyone do what they set out to do, wherever they start from.
4. **Lead by going first.** From Eagle Scouts to expeditions and relay teams: take the first step, then make room for others.
5. **Be honest about results.** Report what failed alongside what worked, and trace each failure to its cause.
